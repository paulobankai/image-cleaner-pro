# Image Cleaner Pro

> Software desktop profissional desenvolvido em Python para higienização em lote e reescrita profunda de metadados em imagens digitais. Sistema de licenciamento por hardware fingerprint.

---

## Visão Geral
O **Image Cleaner Pro** é uma solução robusta para criadores de conteúdo, agências e profissionais que necessitam limpar completamente metadados EXIF, IPTC e XMP de grandes lotes de imagens.

## Stack Tecnológica
- Python · Pillow · NumPy · PyInstaller
